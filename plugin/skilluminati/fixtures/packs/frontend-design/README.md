# frontend-design (web page design)

**What the skill is:** frontend-design, a skill for designing web pages and app screens. It pushes the model away from bland, look-alike pages towards a bold, deliberate visual style.

**Where it came from:** [anthropics/skills](https://github.com/anthropics/skills), commit `41bbe19d1a1a7eaab5e7bb9050a417e5c6cffc8f`, file `skills/frontend-design/SKILL.md`. Copied unchanged.

**Licence:** Apache License 2.0, Copyright Anthropic, PBC. The full text is in `LICENSE.txt`; attribution in `NOTICE`.

**What the questions test:** ten short design briefs (landing pages, sign-up forms, a pricing section, a checkout summary, dashboard cards). Does the skill make the page come back with a distinctive, intentional design instead of a generic one?

**Where the questions came from:** eight from [cowboycodr/sitegeist](https://github.com/cowboycodr/sitegeist) (MIT) and [DogukanUrker/ui-distill-html-648](https://huggingface.co/datasets/DogukanUrker/ui-distill-html-648) (MIT); two written for this test by Claude Sonnet 5.5 (fictional products). Each row in `tasks.jsonl` names its source.

Questions: 10, in `tasks.jsonl`. `SHA256SUMS` holds the fingerprints of `tasks.jsonl` and `SKILL.md`; Skilluminati refuses the pack if either was edited.
